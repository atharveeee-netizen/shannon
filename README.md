## 🌯 Overview
**Shannon** is an autonomous developer platform and agentic optimization compiler designed for Edge AI and TinyML. Named in honor of **Claude Shannon**, the pioneer of Information Theory and digital compression, this studio takes standard machine learning models (PyTorch, ONNX, TensorFlow) and automatically optimizes, quantizes, and compiles them into zero-dependency, ultra-fast C/C++ firmware headers ready to run on resource-constrained microcontrollers (ESP32-S3, STM32H7, ARM Cortex-M, RISC-V) ."
